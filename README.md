# Boring Mortgage — Patriot Home Mortgage

Portable static website. Serve the `dist` directory with any static host. No build dependencies, credentials, database, or contact forms.

## Conversion paths
- Phone and email link to Erik’s official Patriot contact details.
- Application points to Erik’s individual Patriot Homehub signup URL.
- Double-check requests arrange secure sharing through Erik, rather than collecting financial documents on this marketing site.

## Review of original
Original site contained photography copy under loan offerings, a medical billing service, broken /undefined links, broken booking calendar, inconsistent company NMLS numbers, and unsupported potential-savings claims. Rebuilt as Patriot branded campaign, retained Erik’s original portrait and core humor, replaced broken navigation with complete buying, refinance, review, and contact pages.
